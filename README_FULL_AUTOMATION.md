# Freepik 완전 자동화 가이드

## 개요
폴더에서 이미지를 순차적으로 불러와서 Freepik에서 자동으로 합성하고 저장하는 완전 자동화 시스템입니다.

## 구조
- **확장 프로그램**: Freepik 페이지에서 프롬프트 입력, Generate 클릭, 결과 완성 감지, 저장 버튼 클릭
- **외부 프로그램**: 폴더에서 파일 읽기 → 파일 선택 다이얼로그 조작 → 확장 프로그램 버튼 클릭

## 설치

### 1. 확장 프로그램 설치
1. `chrome://extensions` 접속
2. 개발자 모드 활성화
3. `D:\private\코딩\커서\new` 폴더 로드

### 2. Python 프로그램 설치
```bash
pip install pyautogui pyperclip
```

## 설정

### 1. 폴더 경로 설정
`freepik_full_automation.py` 파일에서:
```python
CLOTHES_DIR = Path(r"D:\images\clothes")  # 옷 이미지 폴더
MODELS_DIR = Path(r"D:\images\models")    # 모델 이미지 폴더
```

### 2. 좌표 설정
화면 해상도에 맞게 다음 좌표들을 조정:
- `EXTENSION_ICON_X`, `EXTENSION_ICON_Y`: 확장 아이콘 위치
- `UPLOAD_BUTTON_X`, `UPLOAD_BUTTON_Y`: 파일 업로드 버튼
- `PROMPT_INPUT_X`, `PROMPT_INPUT_Y`: 프롬프트 입력칸
- `RUN_BUTTON_X`, `RUN_BUTTON_Y`: 실행 버튼

### 3. 결과 완성 감지 셀렉터 설정
`contentScript.js`의 `waitForResultAndSave()` 함수에서:
- 결과 이미지 셀렉터
- 저장/다운로드 버튼 셀렉터
를 Freepik 실제 구조에 맞게 수정 필요

## 사용 방법

### 1. Freepik 로그인
일반 크롬 브라우저에서 Freepik에 수동으로 로그인

### 2. 프로그램 실행
```bash
python freepik_full_automation.py
```

### 3. 자동화 흐름
프로그램이 자동으로:
1. 옷 폴더에서 이미지 불러오기
2. 모델 폴더에서 이미지 불러오기
3. 확장 프로그램 팝업 열기
4. 파일 업로드 버튼 클릭
5. 파일 선택 다이얼로그에서 파일 선택
6. 프롬프트 입력
7. 실행 버튼 클릭
8. 결과 완성 대기 (확장 프로그램이 자동 감지)
9. 저장 버튼 클릭 (확장 프로그램이 자동)
10. 다음 조합으로 반복

## 주의사항

### 파일 선택 다이얼로그 자동화 제한
Windows 파일 선택 다이얼로그는 자동화가 제한적일 수 있습니다.
- 자동 선택이 실패하면 수동으로 파일을 선택해야 할 수 있음
- 더 안정적인 방법: 확장 프로그램에서 직접 파일 경로를 받아서 처리 (추가 개발 필요)

### 결과 완성 감지
현재는 고정 시간(20초) 대기 + 기본 셀렉터로 결과 감지 시도
- Freepik 실제 구조에 맞게 셀렉터 수정 필요
- 로딩 스피너 사라짐, 이미지 나타남 등을 정확히 감지하도록 개선 필요

### 좌표 기반 자동화
해상도/화면 크기 변화에 취약할 수 있음
- 이미지 인식 기반 매크로로 전환 고려 (`macro_stable.py` 참고)
- 또는 확장 프로그램 API를 직접 호출하는 방식으로 개선

## 문제 해결

### 파일 선택이 안 됨
- 파일 선택 다이얼로그가 제대로 열렸는지 확인
- 수동으로 파일 선택 후 Enter 키 입력

### 결과 저장이 안 됨
- `contentScript.js`의 저장 버튼 셀렉터 확인
- Freepik 페이지에서 F12 → Elements로 저장 버튼 셀렉터 복사하여 수정

### 좌표가 맞지 않음
- 화면 해상도 확인
- 각 버튼 위치를 다시 측정하여 좌표 수정
