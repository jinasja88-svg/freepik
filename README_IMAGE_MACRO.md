# Freepik 이미지 인식 매크로 가이드

## 개요
좌표 대신 버튼 이미지를 인식해서 클릭하는 방식의 매크로입니다.

## 준비 작업

### 1. images 폴더 생성
프로젝트 폴더에 `images` 폴더가 자동으로 생성됩니다.

### 2. 스크린샷 찍기
각 버튼/요소의 스크린샷을 찍어서 `images` 폴더에 저장하세요:

#### 필요한 이미지:
1. **extension_icon.png** - 확장 프로그램 아이콘
2. **upload_button.png** - 파일 업로드 버튼
3. **prompt_input.png** - 프롬프트 입력칸
4. **run_button.png** - 실행 버튼

#### 스크린샷 찍는 방법:
1. 각 요소를 화면에 표시
2. **Windows + Shift + S** (스크린샷 도구)
3. 해당 요소만 선택해서 캡처
4. `images` 폴더에 저장 (파일명 정확히 맞춰야 함)

#### 팁:
- 배경은 최소한으로, 버튼/아이콘만 찍는 게 좋아요
- 해상도가 바뀌면 다시 찍어야 할 수 있어요
- 확장 팝업은 항상 같은 위치에 열리도록 해주세요

## 사용 방법

### 1. 폴더 경로 설정
`freepik_image_macro.py` 파일에서:
```python
CLOTHES_DIR = Path(r"D:\images\clothes")  # 실제 경로
MODELS_DIR = Path(r"D:\images\models")    # 실제 경로
```

### 2. 실행
```bash
python freepik_image_macro.py
```

## 동작 흐름

1. 확장 아이콘 이미지 찾기 → 클릭
2. 파일 업로드 버튼 이미지 찾기 → 클릭
3. 파일 선택 다이얼로그에서 파일 선택
4. 다시 확장 아이콘 클릭
5. 프롬프트 입력칸 이미지 찾기 → 클릭 → 텍스트 입력
6. 실행 버튼 이미지 찾기 → 클릭

## 문제 해결

### 이미지를 찾을 수 없다는 메시지가 나와요
- 스크린샷이 정확한지 확인
- 화면 해상도가 바뀌었는지 확인
- 요소가 화면에 보이는지 확인
- 스크린샷을 다시 찍어보세요

### 이미지 인식이 느려요
- `confidence` 값을 낮춰보세요 (기본 0.8)
- 스크린샷을 더 작게 찍어보세요
