# Freepik 자동화 매크로 사용 가이드

## 개요
크롬 확장 프로그램과 매크로를 결합하여 Freepik에서 반복 작업을 자동화합니다.

## ⚠️ 중요: 해상도 변화 문제 해결

**좌표 기반 매크로는 해상도/화면 크기 변화에 취약합니다.**

### 해결 방법 1: 확장 프로그램 내장 반복 기능 사용 (추천)
확장 프로그램 팝업에서 **"반복 실행 활성화"** 체크박스를 켜면, 매크로 없이도 자동으로 반복 실행됩니다.
- 해상도 변화에 영향 없음
- 가장 안정적

### 해결 방법 2: 이미지 인식 기반 매크로
`macro_stable.py` 사용 (화면에서 버튼 이미지를 찾아서 클릭)
- 좌표 대신 이미지 패턴 인식
- 해상도 변화에 상대적으로 안정적

## 구성 요소
1. **크롬 확장 프로그램**: Freepik 페이지에서 프롬프트 입력, Generate 버튼 클릭 등 DOM 조작
2. **매크로 스크립트**: 확장 프로그램 팝업의 버튼을 자동으로 클릭

## 설치 및 설정

### 1. 크롬 확장 프로그램 설치
1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 활성화
3. **압축해제된 확장 프로그램 로드** 클릭
4. `D:\private\코딩\커서\new` 폴더 선택

### 2. 매크로 스크립트 선택

#### 방법 A: Python + pyautogui (추천)
```bash
pip install pyautogui pyperclip
python macro_automation.py
```

#### 방법 B: AutoHotkey
1. [AutoHotkey](https://www.autohotkey.com/) 설치
2. `macro_automation_ahk.ahk` 더블클릭하여 실행
3. F1 키 = 한 번 실행, F2 키 = 5번 반복

### 3. 좌표 설정 (중요!)
매크로 스크립트에서 **팝업과 버튼의 화면 좌표**를 정확히 설정해야 합니다.

#### 좌표 확인 방법:
1. 확장 프로그램 팝업을 엽니다
2. Windows의 **마우스 좌표 확인 도구** 사용:
   - AutoHotkey: `CoordMode, Mouse, Screen` 후 `ToolTip` 사용
   - Python: `pyautogui.position()` 함수로 현재 마우스 위치 확인

3. 각 버튼/입력칸의 좌표를 스크립트에 입력:
   - `POPUP_X`, `POPUP_Y`: 팝업 창 위치
   - `PROMPT_INPUT_X`, `PROMPT_INPUT_Y`: 프롬프트 입력칸
   - `UPLOAD_BUTTON_X`, `UPLOAD_BUTTON_Y`: 파일 업로드 버튼
   - `RUN_BUTTON_X`, `RUN_BUTTON_Y`: 실행 버튼

## 사용 방법

### 기본 흐름
1. **Freepik에 수동으로 로그인** (일반 크롬 브라우저에서)
2. Freepik AI 이미지 생성 페이지 열기
3. 매크로 스크립트 실행
4. 매크로가 자동으로:
   - 확장 아이콘 클릭
   - 프롬프트 입력
   - 파일 업로드 버튼 클릭
   - (파일 선택은 수동 또는 추가 스크립트 필요)
   - 실행 버튼 클릭
   - 생성 완료 대기

### 파일 선택 자동화 (선택 사항)
현재 버전에서는 파일 선택 다이얼로그가 열리면 **수동으로 파일을 선택**해야 합니다.

완전 자동화를 원하면:
- Windows 파일 선택 다이얼로그를 조작하는 추가 스크립트 필요
- 또는 확장 프로그램을 수정하여 파일 경로를 직접 전달하는 방식으로 변경

## 주의사항
- 매크로 실행 중에는 **마우스/키보드를 사용하지 마세요**
- 좌표가 정확하지 않으면 버튼을 잘못 클릭할 수 있습니다
- 파일 선택 다이얼로그는 현재 수동 처리 필요
- Freepik 이용약관을 준수하세요

## 문제 해결
- **버튼이 클릭되지 않음**: 좌표를 다시 확인하세요
- **파일 선택이 안 됨**: 수동으로 파일을 선택하세요
- **확장 프로그램이 작동하지 않음**: `chrome://extensions`에서 확장 프로그램을 새로고침하세요
